# 🚁 Drone Flight Plan — live demo

Find a farm field on the map (or draw it), set the take-off spot, mark trees and power lines, and get a
drone mission for **mapping or spraying**: coverage path, flights split by battery and tank, QGroundControl / KML
files.

Code: https://github.com/yuvendhan/drone-flight-plan · Model: https://huggingface.co/yuvendhan/drone-flight-plan-fields
